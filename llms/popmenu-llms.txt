# Popmenu

> Popmenu is an Atlanta-based restaurant technology platform (websites, interactive dynamic
> menus, commission-free online ordering, AI marketing and phone answering, and menu
> management) whose machine interface is a GraphQL API. Popmenu promotes a "Developer API"
> to partners for access to menu, guest and order data, but publishes no schema,
> authentication reference, or base URL — access is arranged through a sales conversation.

## What is actually callable

- [GraphQL endpoint](https://api.popmenu.com/graphql): POST, `Content-Type: application/json`.
  Verified live 2026-08-13 (HTTP 200). Introspection and every query return
  `{"errors":[{"message":"unauthorized", ...}]}` without partner credentials, so the schema
  cannot be discovered anonymously.
- [Alternate GraphQL endpoint](https://my.popmenu.com/graphql): the same service on the
  application host; identical response envelope and `popmenu-version` build header.
- There is **no REST API, no OpenAPI/Swagger document, no AsyncAPI, no webhook catalog, no
  MCP server and no A2A agent card**. Every discovery path was probed and returned 404 on
  the reachable hosts.

## Getting access

- [Developer API page](https://get.popmenu.com/developer-api): a lead-capture form, not
  documentation. Submitting it lands on `/success-api` — "We'll be reaching out to you soon."
- There is no self-service signup, no sandbox, no published key format, and no scope list.

## Runtime behaviour an agent should know

- Errors return **HTTP 200** with a GraphQL `errors` array; a non-standard `friendlyMessage`
  sits alongside `message` instead of under `extensions`. There are no machine-readable
  error codes.
- Rate limiting is signalled with vendor-prefixed headers — `popmenu-ratelimit-limit`,
  `popmenu-ratelimit-remaining`, `popmenu-ratelimit-reset` — not `RateLimit-*` or
  `X-RateLimit-*`. No `Retry-After` was observed.
- Correlation is via the `x-request-id` response header only; it is not echoed in the body.
- `popmenu-version` carries a git SHA, not an API version. There is no versioning or
  deprecation policy.

## Agent access policy

- [robots.txt](https://my.popmenu.com/robots.txt): `Disallow: /` for all user agents, with
  narrow `Allow` exceptions for `facebookexternalhit` only.
- The marketing estate (`get.popmenu.com`, `popmenu.com`, `www.popmenu.com`,
  `support.popmenu.com`) returns **403 to every non-browser client**, including
  `robots.txt`. Automated readers cannot reach Popmenu's own product or support content.

## Product surface

- [Restaurant websites](https://get.popmenu.com/restaurant-website-design) — SEO-driven,
  WCAG-conformant sites with menu-driven content.
- [Interactive dynamic menus](https://get.popmenu.com/dynamic-menu-tech) — photo-rich,
